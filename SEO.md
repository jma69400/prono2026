## 🎯 Étape 1 — Soumettre ton site à Google (URGENT, fais-le aujourd'hui)

### A. Google Search Console (le plus important)

1. Va sur **https://search.google.com/search-console**
2. **Ajouter une propriété** → **Préfixe d'URL** : `https://unitedpronos.com`
3. **Vérification** : Google te donne plusieurs méthodes. La plus simple = **Fichier HTML** :
   - Télécharge le fichier `googleXXXXX.html`
   - Place-le dans `frontend/public/` (à côté de `robots.txt`)
   - Push GitHub + redéploiement
   - Clique "Vérifier" dans Search Console
4. Une fois vérifié → **Sitemaps** dans le menu de gauche
5. **Ajouter un sitemap** : tape `sitemap.xml` → Envoyer
6. Vérifie l'**Indexation** quelques jours plus tard

> ⏱️ Google indexera ton site dans **2-7 jours**.

### B. Bing Webmaster Tools (10% des recherches FR)

1. https://www.bing.com/webmasters/
2. Ajoute `unitedpronos.com`
3. Importe direct depuis Google Search Console (option en 1 clic)

### C. Soumets aux moteurs alternatifs
- DuckDuckGo : indexe automatiquement (utilise Bing)
- Qwant : pareil
- Yandex Webmaster (si tu vises l'Europe de l'Est)

## 🎯 Étape 7 — Performance technique avancée

### Compression des images (gain énorme)
Convertis tes images en **WebP** (50% plus léger que JPG) :
```bash
# Sur ton PC
cwebp -q 85 image.jpg -o image.webp
```

### Cache navigateur (déjà fait)
Ton `nginx.conf` a déjà : `expires 1y` pour CSS/JS/images. ✅

### Compression gzip/brotli (déjà fait)
Caddy fait `encode gzip`. Pour ajouter brotli (gain 15% supplémentaire) :
```
prono2026.fr {
    encode gzip zstd
    reverse_proxy frontend:80
}
```

### CDN (Cloudflare)
Active Cloudflare en mode **proxy** (nuage orange) — ça met ton site dans un CDN mondial. Plus rapide partout.
